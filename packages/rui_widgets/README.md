# rui_widgets

Concrete widgets.

Part of the [RUI2](https://github.com/kobi2187/rui2) monorepo. Self-contained and
`git subtree split`-ready (see [SPLITTING.md](../../SPLITTING.md)).

**Depends on:** rui_core, rui_drawing, naylib

```nim
import rui_widgets
```

Primitives (label, rectangle, circle), basic controls (button, checkbox,
radiobutton, slider, progressbar, hyperlink, image) and containers (vstack,
hstack, zstack, scrollview).
