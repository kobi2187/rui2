# rui_drawing

Drawing primitives and the theme system.

Part of the [RUI2](https://github.com/kobi2187/rui2) monorepo. Self-contained and
`git subtree split`-ready (see [SPLITTING.md](../../SPLITTING.md)).

**Depends on:** rui_core, naylib, yaml

```nim
import rui_drawing
```

Drawing primitives, visual effects, the theme system (`ThemeState` ×
`ThemeIntent` with cascading resolution), the text cache, and theme-aware widget
primitives.
